# MiniHost 微信小程序基础库

本仓库为 MiniHost 提供微信小程序基础库文件，是非微信官方仓库。MiniHost 可通过固定 Git 提交安装依赖。

## 文件来源

- `3.18.0`：从微信开发者工具下载的同版本 `.wxvpkg` 完整解包，文件内容未经修改。
- `3.7.0`：来自 [`@open-wxa/wxa-baselib@0.1.0`](https://www.npmjs.com/package/@open-wxa/wxa-baselib)，用于兼容已有配置。
